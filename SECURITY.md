# Security Policy

## Supported Versions

This is a new project without any releases yet, so any security vulnerabilities will be considered prior to releaseing v1.0.

| Version | Supported          |
| ------- | ------------------ |
| any   | :white_check_mark: |

## Reporting a Vulnerability

Post in the Issue Queue for now. Before w get to v1.0 we'll add a reporting tool inside the app specifically for this purpose that will submit a secure message to the developer team.
